Smart Lock System with OTP Authentication

Author: Harsha Vardhan Goud • Platform: C++ (OpenSSL) • Target: WSL / Linux / Embedded

Abstract

This project implements a secure Smart Lock system that combines a static PIN with Time-Based One-Time Password (TOTP) authentication generated by authenticator apps (Google Authenticator / Microsoft Authenticator). Implemented in C++ and using OpenSSL for cryptographic operations, the system uses a 30-second TOTP interval and HMAC-SHA1 to produce 6-digit OTPs, providing robust two-factor authentication for offline-capable locks.

Introduction

Single-factor methods (PINs, keys) are vulnerable to theft and brute force. Combining a PIN with TOTP creates a practical multi-factor solution appropriate for smart homes and small physical access control systems. This documentation covers design, implementation, debugging, compiling, and deployment steps.

System Architecture

  • PIN Layer: Local PIN entry verified before OTP request.
  • TOTP Layer: Shared Base32 secret decoded into raw bytes; HMAC-SHA1 over time step; truncation yields 6-digit OTP.
  • Authenticator: Mobile app (Google Authenticator, etc.) provides user OTP.
  • Control: Accept OTP and simulate unlocking (console / LED / GPIO).

Build & Run (Ubuntu / WSL)

Install dependencies:

sudo apt update
sudo apt install build-essential libssl-dev -y

Compile and run:

cd "/mnt/d/Projects/Smart-Lock-System-with-TOTP-Authentication"
g++ main.cpp TOTP.cpp -std=c++11 -lssl -lcrypto -o smartlock
./smartlock

Authenticator Setup (Manual)

Debugging & Time Sync

  • Enable debug output in code to print Unix time, time step, and generated OTP.
  • Sync WSL time if OTPs mismatch:
    • sudo apt install ntpdate -y
sudo ntpdate time.google.com
  • Alternatively restart WSL to pick up Windows clock:
    • powershell.exe -Command "wsl --shutdown"

Results & Limitations

The system successfully validates OTPs in the standard 30-second window when clocks are synced. Limitations include a single hardcoded PIN and lack of user administration and encryption for stored PINs.
